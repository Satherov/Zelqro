# Zelrqo

Just a tiny java library for the stuff I reuse across all my projects.
Mainly shortcuts for ternary operators and other random stuff.

I don't exactly plan on anyone else using this, so...

## Mapping

The currently biggest part of this library are mapping utilities, 
simply because I don't like ugly ternary operators :3

See the mapping package for the different mapping utilities.

## Functions

Since base java only provides Functions and Suppliers for Ints, Longs and Doubles,
the missing ones are provided here.

## Utils

String utils for basic formatting I keep reimplementing, so now also here.
